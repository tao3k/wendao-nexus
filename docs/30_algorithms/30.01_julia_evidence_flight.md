# 30.01 Julia Evidence Flight

This document defines the first Julia-side evidence judgement contract for
Wendao Nexus. It is protocol documentation only. This repository does not create
a Julia package, start a Flight server, or implement advanced algorithms in this
phase.

## Route

```text
/knowledge/evidence/judge
```

The route consumes Arrow batches shaped like Nexus search or compare evidence
rows. Rust Nexus remains responsible for ingestion, source identity,
provenance, `SourceAuthorityProfile`, and deterministic basic authority
judgement. Julia-side services may add advanced scoring later.

## Input Columns

The first judge input should accept these Nexus evidence columns when present:

```text
source_id
external_id
canonical_uri
authority_level
published_at
fetched_at
doi
pmid
jurisdiction
evidence_kind
snippet
provenance_json
metadata_json
trust_score
freshness_score
```

`trust_score` and `freshness_score` are Rust basic judgement outputs. Missing
optional score columns should be treated as unknown, not as zero.

## Output Columns

The first judge output batch should contain:

```text
source_id
external_id
rust_trust_score
julia_evidence_score
corroboration_score
conflict_score
pollution_risk_score
freshness_adjusted_score
final_evidence_score
judgement_label
explanation_json
```

`judgement_label` is a compact label such as `trusted`, `needs_review`,
`insufficient_evidence`, or `conflict_present`. `explanation_json` is a compact
machine-readable summary, not model prose.

## Algorithm Boundary

Rust basic judgement is deterministic and auditable. Julia should focus on work
that benefits from columnar analytics and graph/statistical routines:

- duplicate or near-duplicate evidence clustering;
- independent source counting;
- source authority propagation;
- temporal drift checks;
- conflict grouping;
- pollution-risk and spam-signal scoring.

The first Julia implementation can be a downstream package such as
`WendaoEvidence.jl`, but that package is not part of this repository in the
Real Source Probe phase.
