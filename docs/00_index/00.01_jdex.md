# 00.01 JDex

This is the Johnny.Decimal index for Wendao Nexus documentation.

## Topology Authority

The project-local category catalog lives in `docs/topology.toml`. It follows
the path-first contract:

- category semantics come from `docs/topology.toml`;
- note coordinates come from the `AC.ID` prefix in the file path;
- note files use `AC.ID_semantic_name.md`;
- the leading category prefix in the directory must agree with the file
  coordinate.

## Authoring Rule

New documents should first choose a declared category in `docs/topology.toml`,
then select an unused `AC.ID` slot in that category. If no existing category is
right, propose a manifest diff for review instead of silently creating a new
meaning.

After writing documentation, run the local validation commands in
`docs/90_operations/90.01_validation_and_governance.md`.
